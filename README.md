## Пример

### Часть 1: Коты

| Тест | Входные данные | Ожидаемый результат |
|:-----|:---------------|:--------------------|
| **Кот мяукает 1 раз** | `new Cat("Барсик").Meow()` | Вывод: "Барсик: мяу!" |
| **Кот мяукает 3 раза** | `new Cat("Барсик").Meow(3)` | Вывод: "Барсик: мяу-мяу-мяу!" |
| **Полиморфизм IMeowable** | `MeowCare(кот, собака, робот)` | Кот: "Барсик: мяу!"<br>Собака: "Шарик: гав?"<br>Робот: "R2D2: Бип-бип-мяу!" |
| **Подсчет мяуканий** | `MeowCounter` декоратор | Кот мяукает, счетчик увеличивается |

### Часть 2: Дроби

| Тест | Входные данные | Ожидаемый результат |
|:-----|:---------------|:--------------------|
| **Сложение дробей** | 1/2 + 2/3 | **7/6** |
| **Вычитание дробей** | 2/3 - 1/2 | **1/6** |
| **Умножение дробей** | 1/2 * 2/3 | **2/6 = 1/3** |
| **Деление дробей** | 1/2 / 2/3 | **3/4** |
| **Сравнение дробей** | 1/2 == 2/4 | **true** |
| | 1/2 == 1/3 | **false** |
| **Клонирование** | clone = (Fraction)original.Clone() | Новый объект с теми же значениями |
| **Кэширование** | `cached.GetDoubleValue()`<br>два раза подряд | 1-й раз: вычисление<br>2-й раз: из кэша |
