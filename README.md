##Пример
### Задания 6-7 (RightTriangle)

| Тест | Входные данные | Ожидаемый результат |
|:-----|:---------------|:--------------------|
| **Конструктор по умолчанию** | `new RightTriangle()` | a=1, b=1 |
| **Конструктор с параметрами** | `new RightTriangle(3,4)` | a=3, b=4 |
| **Площадь треугольника** | (3,4) | **6** |
| | (5,12) | **30** |
| **Унарный ++** | (3,4) → `++t` | (6,8) |
| **Унарный --** | (6,8) → `--t` | (3,4) |
| **Явное приведение к double** | (3,4) → `(double)t` | **6.0** |
| **Неявное приведение к bool** | (3,4) → `if (t)` | **true** |
| | null → `if (t)` | **false** |
| **Сравнение <=** | t1(3,4) площадь=6, t2(5,12) площадь=30 | **t1 <= t2 = true** |
| **Сравнение >=** | t1(3,4) площадь=6, t2(5,12) площадь=30 | **t1 >= t2 = false** |
| **Сравнение равных площадей** | t1(3,4) площадь=6, t3(6,8) площадь=24 | **t1 <= t3 = true**<br>**t1 >= t3 = false** |
