## Примеры
#### Задание 1.4 - List

| Тест | Входные данные | Ожидаемый результат |
|:-----|:---------------|:--------------------|
| **Обычный случай** | L = [1,2,3,1,4,5,1,6], E = 1 | **[1,3,1,5,1]** |
| **Элементы подряд** | L = [1,1,2,3,1], E = 1 | **[1,1,3,1]** |
| **Пустой список** | L = [], E = 5 | **[]** |

#### Задание 2.4 - LinkedList

| Тест | Входные данные | Ожидаемый результат |
|:-----|:---------------|:--------------------|
| **Есть равные соседи** | [1,2,2,3] | **true** |
| **Нет равных соседей** | [1,2,3,4] | **false** |
| **Первый = последний** | [1,2,3,1] | **true** |
| **Один элемент** | [5] | **false** |

#### Задание 3.4 - HashSet (Страны и туристы)

| Тест | Входные данные | Ожидаемый результат |
|:-----|:---------------|:--------------------|
| **Все туристы** | Турист1: Россия, США, Франция<br>Турист2: Россия, Китай, Франция<br>Турист3: США, Италия, Франция | **Все:** {Франция}<br>**Некоторые:** {Россия, США, Китай, Италия}<br>**Никто:** {} |

#### Задание 4.4 - HashSet + файл (глухие согласные)

| Тест | Входные данные | Ожидаемый результат |
|:-----|:---------------|:--------------------|
| **Текст с разными словами** | "кот пес дом сад лес" | Глухие согласные в 1 слове:<br>к (кот), п (пес), д (дом), с (сад), л (лес) |

#### Задание 5.4 - Dictionary (абитуриенты)
