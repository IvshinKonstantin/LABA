## 📌 О проекте

Консольное приложение на C#, демонстрирующее основные принципы объектно-ориентированного программирования:
- **Инкапсуляция** - свойства с private set, проверка данных в конструкторах
- **Наследование** - не используется в данном проекте
- **Полиморфизм** - переопределение метода ToString()
- **Абстракция** - создание сущностей, моделирующих реальные объекты
