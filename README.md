# Лабораторная работа №3 - Вариант 4

## Общая информация
**Тема:** Массивы и файлы  
**Вариант:** 4 (все задания под номером 4)  
**Язык:** C#  
**Тип проекта:** Консольное приложение


## Содержание заданий

| Задание | Номер варианта | Описание |
|---------|----------------|----------|
| 1.4 | 4 | Заполнение двумерных массивов |
| 2.4 | 4 | Поиск минимального повторяющегося элемента |
| 3.4 | 4 | Вычисление матричного выражения 2*A - B^T * C |
| 4.4 | 4 | Подсчет пар противоположных чисел в бинарном файле |
| 5.4 | 4 | Поиск багажа со средней массой, близкой к общей |
| 6.4 | 4 | Проверка наличия нуля в текстовом файле |
| 7.4 | 4 | Поиск максимального элемента в файле |
| 8.4 | 4 | Копирование строк, оканчивающихся на заданный символ |

## Системные требования
- Visual Studio 2019 или новее
- .NET Framework 4.7.2 или .NET Core 3.1
- Windows 7/8/10/11

## Быстрый старт
1. Создать новый проект "Консольное приложение" с именем "ЛАБА 3"
2. Заменить Program.cs на предоставленный файл
3. Добавить остальные файлы в проект
4. Собрать решение (Ctrl+Shift+B)
5. Запустить (F5)

## Создаваемые файлы
| Имя файла | Тип | Назначение |
|-----------|-----|------------|
| numbers.dat | Бинарный | Числовые данные для задания 4 |
| passengers.xml | XML | Данные пассажиров для задания 5 |
| numbers_single.txt | Текстовый | Числа по одному в строке |
| numbers_multiple.txt | Текстовый | Несколько чисел в строке |
| source_text.txt | Текстовый | Исходный текст |
| filtered_text.txt | Текстовый | Отфильтрованный текст |
